# E-commerce-Store
Arsh-Store - Core PHP e-commerce for Electronics, Clothing, Shoes, Grocery &amp; Mobiles. User: category-wise products, detail page, responsive design. Admin: secure login (admin/admin123), add/edit/delete products with images, manage categories &amp; stats. Stack: PHP, MySQL, HTML/CSS, JS. DB: ecommerce_db (products, orders, order_items, users).
